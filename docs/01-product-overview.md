# Product Overview

## 1. Product Name

Jemput Jelantah

## 2. Product Summary

Jemput Jelantah is a scheduled used cooking oil (UCO) collection and aggregation platform that consolidates fragmented supply from households and culinary micro-UMKM into denser pickup routes.

## 3. Problem

Used cooking oil supply is fragmented across households and small culinary businesses. Individually, each supplier may contribute limited volume, making pickup routes difficult to consolidate efficiently.

## 4. Target Users

### Primary Target

- Culinary micro-UMKM
- Households located around existing collection areas

### Geographic Focus

Jember, East Java, as the initial pilot market.

## 5. Product Hypothesis

If UCO from nearby households is aggregated around culinary micro-UMKM anchors, the combined volume can increase toward the internal 50L pilot operating threshold and improve route utilization.

## 6. Value Proposition

Jemput Jelantah provides:

- Scheduled area-based pickup
- Collection progress visibility
- Transparent weighing
- Clear supplier payout

## 7. Product Positioning

Jemput Jelantah is positioned as an aggregation and scheduled pickup layer that consolidates fragmented UCO supply before collection routes are dispatched.

## 8. Core Mechanism

Fragmented Supply  
→ Aggregated Volume  
→ Route Efficiency  
→ Verified Payout

## 9. Product Loop

COLLECT  
→ SCHEDULE  
→ TRACK  
→ WEIGH  
→ GET PAID

## 10. MVP Scope

The MVP focuses on:

- Supplier registration
- Supplier type selection
- Estimated volume input
- Area-based pickup scheduling
- Route aggregation
- Collection progress tracking
- Route status
- Weighing
- Supplier payout calculation
- Pricing reference
- Basic transaction validation

## 11. Out of Scope

The MVP does not include:

- Downstream UCO processing
- Geographic expansion beyond the pilot
- Advanced route optimization
- Real-time market pricing
- Supplier marketplace
- Automated demand forecasting

## 12. Tech Stack

- Google Apps Script
- HTML
- CSS
- JavaScript
- Google Sheets

## 13. Core Product Flow

HOME

→ INPUT ESTIMATED VOLUME  
→ SELECT AREA  
→ SELECT PICKUP SCHEDULE  
→ CONFIRM REQUEST  
→ AREA AGGREGATION

→ PICKUP  
→ WEIGHING  
→ PAYOUT

## 14. Project Objective

The MVP aims to validate whether fragmented UCO supply from households and culinary micro-UMKM can be consolidated into sufficiently dense pickup routes while maintaining a transparent supplier experience.

## 15. Pilot Operating Threshold

50L is used as an internal pilot operating threshold to test whether route aggregation can reach a meaningful volume before geographic expansion.

It is not presented as an external industry benchmark or proven break-even point.
